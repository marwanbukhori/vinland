# Admin
Contain dashboard
Create, edit, delete activities
Can manually register users on activity
Manage participant list (add, remove)
Have organized activity page (list of activity organized)
Manage vouchers (create, deactivate, edit)
View analytics (most popular activities, number of volunteers, total hours served)
Cannot join activities
Cannot claim vouchers
Cannot earn points/exp

# User
Join activity using QR code
Earn points & EXP automatically after completing activity
Claim vouchers using points
View ranking leaderboard
Chat in activity group chat in activity detail page
Have my activity page (joined activity list)
Leave reviews after activity ends
View activity history & statistics (total volunteering hours, ranking progress)
